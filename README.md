# Banking System Using Python 🏦

## Project Overview

This is a simple banking system developed using Python as part of my Core Python Module 1 End Project. It simulates basic banking operations through a menu-driven program.

## Features

* **Account Login:** Authenticate users using an account number and PIN.
* **Check Balance:** Display the current account balance.
* **Deposit Money:** Deposit money and update the balance.
* **Withdraw Money:** Withdraw money while checking the available balance.
* **Input Validation:** Prevent zero or negative deposit and withdrawal amounts.
* **Exit:** Safely exit the banking system.

## Technologies Used

* Python 3
* Jupyter Notebook

## How to Run

1. Clone or download this repository.
2. Open the Jupyter Notebook.
3. Run the code cells.
4. Enter the account credentials when prompted.
5. Select an operation from the banking menu.

## Learning Objectives

This project demonstrates the use of:

* Variables and data types
* Conditional statements (`if`, `elif`, `else`)
* Loops (`while`)
* User input and output
* Arithmetic and comparison operators
* Basic input validation

## Limitations

This project is an educational simulation. Account details and balances are stored in variables and are not saved permanently. It is not intended for real banking use.
